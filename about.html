About Rosetta

What is Rosetta?

Rosetta is a free language translator that works right in your browser. It supports 40+ languages including all major Indian regional languages — Hindi, Gujarati, Marathi, Tamil, Telugu, Bengali, Kannada, Malayalam, and more — plus global languages like Spanish, French, German, Arabic, Chinese, Japanese, and Korean.

Unlike many translation apps, Rosetta does not require sign-up or installation. Just open the page and start translating.

Features

  • Text translation — Translate text between 40+ languages instantly.
  • Voice translation — Speak and get a spoken translation in reply.
  • Conversation mode — Two people talk on one device; each reply is translated and read aloud in the other language.
  • Video-call translation — Start a room, share the code, and see each other's speech as real-time translated subtitles over a peer-to-peer call.
  • Indian language pages — Dedicated pages for English → Hindi, Gujarati, Marathi, and Tamil translation with extra tips.

Technology

Rosetta is a pure HTML + CSS + JavaScript app with no build step or framework. Translation is powered by the Google Translate API and MyMemory as a fallback. Voice features use the browser's built-in Web Speech API. Video calls use WebRTC for peer-to-peer connections.
