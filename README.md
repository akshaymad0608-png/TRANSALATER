# Rosetta — Free Voice & Text Translator

**Live site:** [languagetransalator.com](https://languagetransalator.com)

Translate by typing or speaking, hear the result read aloud, and hold a live two-way conversation. Free, no sign-up, works in the browser on mobile.

It is a static site (HTML, CSS and a service worker) with per-language landing pages such as English to Hindi, Marathi, Gujarati, Tamil and Telugu, plus the reverse directions.
